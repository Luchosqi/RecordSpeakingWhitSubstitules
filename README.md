# Prompter Cam

Escribe tu guion, elige cuánto debe durar y grábate con la cámara mientras el texto aparece abajo, tipo subtítulo, al ritmo justo.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build && npm run preview   # versión instalable (PWA)
```

Atajos en el estudio: **Espacio** grabar/detener · **R** reintentar · **P** pausar texto · **↑/↓** velocidad · **←/→** saltar línea · **Esc** cancelar.
